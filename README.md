# BIQU Belter

Belter is a digital belt tension measurement tool for 3D printers, designed for belt setup, belt matching, and repeat adjustment.

## Calibration & Calculation

The latest Belter workflow includes:

- Basic Belter calibration using **Belter Calibration Reading** and **Belt Thickness**
- **Compare Belts** and **Single Belt** measurement modes
- A default nonlinear tension model for normal use
- Optional **Calculation Model Calibration** using 500–2000 g test data for users who want the best possible absolute tension accuracy
- Preset or custom tension ranges in the Web Tool

For most users:

`Calibrate Belter → Measure Belts Normally`

For advanced users:

`Calibrate Belter → Optional Calculation Model Calibration → Measure Belts Normally`
